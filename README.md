# Inclusive digital services: a serious game

A serious game built with the Lyon metropolitan area to raise awareness of inclusiveness and
accessibility among the people who design public digital services. It was a team project at
Centrale Lyon (September 2024 - April 2025).

The game has three web apps, each in its own repository (git submodules):

| Module | What it does | Live demo |
|---|---|---|
| [Jeu](https://github.com/foucblg/Jeu) | The main game: players register for a workshop, go through diagnostic cards on each phase of a digital project, and get tasks assigned | [foucblg.github.io/Jeu](https://foucblg.github.io/Jeu/) |
| [Quiz](https://github.com/foucblg/Quiz) | A quiz on inclusiveness, with weighted question categories, driven by a JSON file | [foucblg.github.io/Quiz](https://foucblg.github.io/Quiz/) |
| [Auto-evaluation](https://github.com/foucblg/Auto-evaluation) | A self-assessment of how inclusive your own digital service is | [foucblg.github.io/Auto-evaluation](https://foucblg.github.io/Auto-evaluation/) |

Stack: Angular 18, TypeScript, deployed with GitHub Pages.
